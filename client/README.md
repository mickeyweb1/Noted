# 📚 Noted | study.butlouder

A modern, responsive student study dashboard designed to transform messy lecture notes into actionable audio summaries, interactive quizzes, and focused study sessions. 

## ✨ Features

- 🎨 **Modern UI/UX**: Built with Tailwind CSS v4 and shadcn/ui for a clean, accessible interface.
- 🌗 **Dark/Light Mode**: Seamless theme toggling with persistent user preference.
- 📱 **Fully Responsive**: Adaptive layout with a collapsible mobile sidebar and desktop-optimized workspace.
- 🔐 **Authentication UI**: Complete Login, Sign Up, and Forgot Password flows.
- 🧭 **Smart Navigation**: React Router setup with active state tracking and keyboard shortcuts (`Cmd/Ctrl + K` for search).
- 📊 **Dashboard Modules**: Dedicated routes for Dashboard, AI Generator, My Library, Quiz, Focus Time, and Settings.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: Tailwind CSS v4, shadcn/ui, CSS Variables (OKLCH)
- **Icons**: Lucide React
- **Routing**: React Router DOM
- **State Management**: React Context API

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mickeyweb1/Noted.git
   cd client

2. Install dependencies:
    npm install

3. Start the development server:
   npm run dev

4. Open your browser and navigate to http://localhost:5173
